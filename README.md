# 瞬英トレーナー

ビジネスシーンを中心にした **瞬間英作文** のトレーニングアプリです。日本語の文を見て、すぐに英語で話す（または入力する）練習を繰り返し、「考えずに口から英語が出る」状態を目指します。

- **音声で回答するのが基本**です。マイクに向かって英語で話すと、自動で判定します。
- **キーボード入力（電車モード）** にも対応しています。声を出せない場所ではワンタップで切り替えられます。
- **ビジネス9シーン＋日常2シーン × 4レベル、計352文**を収録しています。最初にシーンとレベルを選んで始めます。
- スマホのホーム画面に追加して使える **PWA** です。教材と判定はオフラインでも動作します。

---

## 起動方法

### パソコンで使う

```bash
npm start
```

ブラウザで http://localhost:8765 を開きます（`python3 -m http.server 8765` でも同じです）。音声入力を使うなら **Chrome** をおすすめします。

### スマホで使う

ブラウザの音声認識とマイクは **HTTPS 接続でしか動きません**。スマホで使うときは、このフォルダを丸ごと静的ホスティングに置いてください（ビルドは不要です）。

- GitHub Pages / Netlify / Cloudflare Pages / Vercel など、どれでも使えます
- 公開したURLを開いて、共有メニューから「ホーム画面に追加」するとアプリとして起動できます

| 端末 | 音声入力 | 備考 |
|---|---|---|
| iPhone / iPad（Safari） | ○ | iOS 14.5 以降。初回にマイクと音声認識の許可が必要です |
| Android（Chrome） | ○ | |
| PC（Chrome / Edge） | ○ | Space キーで録音、Enter で次へ |
| Firefox | × | キーボード入力のみ |

※ ブラウザの音声認識は、端末やブラウザ提供元（Apple / Google）のサービスを利用します。

## 使い方

1. **回答方法を選ぶ**：「音声で答える」または「キーボード（電車モード）」。トレーニング中も右上のボタンで切り替えられます。
2. **シーンを選ぶ**：「ビジネス」「日常」「おまかせ（複数シーンを混ぜて出題）」のタブから選びます。
3. **レベル・出題方法・問題数を選んでスタート**します。
4. 日本語が表示されたら、**すぐに英語で話し始めます**。話し始めるまでの「反応時間」を計測し、制限時間（初期設定は5秒）を超えると時間オーバーになります。
5. 判定・模範解答・別解・ポイント解説を確認します。🔊 ボタンでお手本の音声を聞けます。

| 判定 | 意味 | 次に出題されるタイミング |
|---|---|---|
| ◎ Perfect | 制限時間内に正解 | 1→3→7→14→30→60日後（正解するたびに間隔が延びる） |
| ○ 正解 | 正解したが時間オーバー、またはヒントを使用 | 間隔は延びない |
| △ 惜しい | 小さな違いがある | 翌日 |
| × 不正解 | 違いが大きい、または「答えを見る」を選んだ | すぐ（セッションの最後にもう一度） |

- 判定が納得できないとき（音声の誤認識など）は「判定を修正」で ◎ / × に変更できます。
- 「もう一度」で何度でも言い直せます。学習記録には1回目の結果が保存されます。
- ホームの「復習待ち」から、期限が来た文をまとめて復習できます。
- 「フレーズ帳」では全352文を一覧・検索でき、英文を隠して暗記チェックもできます。

## コンテンツ設計

### レベル（ビジネスでの到達目標が基準）

| レベル | 到達目標 | 主な文法・表現 | 目安 |
|---|---|---|---|
| Lv1 ベーシック | 定型表現で挨拶・依頼・確認ができる | 基本文型・命令文・Can/Could | TOEIC 〜550 / CEFR A2 |
| Lv2 スタンダード | 状況や自分の意見を簡潔に説明できる | 助動詞・不定詞・動名詞・現在完了 | TOEIC 550-750 / CEFR B1 |
| Lv3 アドバンス | 根拠を示しながら提案・調整ができる | 仮定法・関係詞・間接疑問・クッション言葉 | TOEIC 750-900 / CEFR B2 |
| Lv4 エキスパート | 交渉や進行でニュアンスを使い分けられる | 婉曲表現・イディオム・複文の組み立て | TOEIC 900+ / CEFR C1 |

日常シーンも同じ4段階の難易度で作っています。

### シーン（各シーン 4レベル × 8文 = 32文）

| 区分 | シーン | 内容 |
|---|---|---|
| ビジネス | 会議・ディスカッション | 進行・意見・合意形成 |
| | 電話・Web会議 | 取り次ぎ・接続トラブル・オンライン進行 |
| | メール・チャット | 依頼・催促・お詫び・結びの定型 |
| | プレゼン・報告 | 構成・数字の説明・質疑応答 |
| | 交渉・商談 | 価格・条件・譲歩・合意 |
| | 社内コミュニケーション | 依頼・相談・報連相・お詫び |
| | マネジメント・1on1 | 目標設定・フィードバック・評価 |
| | 顧客対応・接客 | 案内・クレーム対応・お詫び |
| | 出張・会食 | 名刺交換・会食・ネットワーキング |
| 日常 | 日常会話・雑談 | 趣味・近況・気持ちを伝える |
| | 旅行・外出 | 交通・ホテル・レストラン・トラブル |

各文には、模範解答、**別解（3〜5通り）**、覚えるべきキーフレーズ（模範解答の中で強調表示）、必要に応じてポイント解説を付けています。

## 判定のしくみ

瞬間英作文では正解が1つに決まらないため、次の3段階で判定しています。

1. **表記ゆれの吸収**（`js/grader.js`）
   - 短縮形を展開します（I'm → I am、don't → do not。'd は would / had、's は is / has のどちらとも一致）。
   - 数字・記号を読みに直します（10% → ten percent、9 a.m. → nine am、5,000,000 → five million）。
   - 大文字小文字、句読点、英米の綴りの違い（cancelled / canceled など）、アポストロフィの省略（dont, lets）も吸収します。
2. **単語単位の重み付き編集距離**で、模範解答とすべての別解を照合し、最も近いものを採用します。
   - 冠詞や please などの付け足し・抜けは軽い減点です。
   - 1文字違いのタイプミスや、同音語の誤認識（to / too / two など）も軽い減点にとどめます。
   - 音声認識の別候補（最大5件）もすべて照合します。
   - 一致度が90%以上なら正解、70%以上なら惜しい、それ未満は不正解です（設定で「やさしい／標準／きびしい」に変更できます）。
3. **AI添削（任意）**：別解にない言い回しでも、Claude が意味と自然さを判定し、日本語でフィードバックと改善例を返します。AIの判定は結果を引き上げる方向にだけ使います。

結果画面では、あなたの回答と模範解答の違いを赤（違い・抜け）と黄（つづり・発音が近い語）で表示します。

## AI添削の設定（任意）

1. [Anthropic Console](https://console.anthropic.com/) で APIキーを発行します。
2. アプリの「設定 → AI添削（任意）」をオンにして、APIキーを入力します。
3. モデルを選びます。初期設定は Claude Opus 5.5 で、速さや費用を重視するなら Sonnet 5.5 / Haiku 5.5 も選べます。

- 「不正解・惜しいときは自動で添削」がオンなら自動で添削し、オフなら結果画面のボタンで依頼します。
- **APIキーはこの端末のブラウザにのみ保存**され、回答文とともに Anthropic の API へ直接送信されます。共用の端末では設定しないでください。バックアップ（書き出し）にもAPIキーは含まれません。
- API の利用料金がかかります。
- この機能を使うときだけ、公式 SDK（`@anthropic-ai/sdk`）を CDN（esm.sh）から読み込みます。

## 教材の追加・編集

教材は `js/data/scenes/*.js` にあります。1文の書式は次のとおりです。

```js
{
  ja: "締め切りを1週間延ばせますか？",            // 問題文（日本語）
  en: "Can we extend the deadline by a week?",   // 模範解答
  alt: ["Could we extend the deadline by a week?", "..."], // 別解（正解として扱う）
  key: "extend the deadline",                    // 強調するキーフレーズ（en に含まれる語句。離れた語句は "not only ... but also" と書く）
  note: "「〜だけ」の差は by で表す。",            // ポイント解説（省略可）
}
```

- レベルごとに `1: [...]` 〜 `4: [...]` の配列に入れます。
- 新しいシーンを追加するときは、`js/data/scenes/` にファイルを作り、`js/data/index.js` の `SCENES` に1行追加します。
- 学習記録は日本語文から作るIDで管理しています。そのため、並び替えても記録は引き継がれますが、日本語文を書き換えた文は新しい問題として扱われます。
- 編集したら `npm test` を実行してください。模範解答・別解が自分自身と完全一致するか、キーフレーズが模範解答に含まれているかを自動でチェックします。
- オフライン用のキャッシュ対象は `sw.js` の `ASSETS` です。ファイルを追加したらここにも追記し、`CACHE` の名前を変えてください。

## 構成

```
index.html              画面の土台
css/style.css           スタイル（ライト／ダーク対応）
js/app.js               画面・トレーニングの進行
js/grader.js            回答の正規化と判定エンジン
js/speech.js            音声認識（Web Speech API）と読み上げ
js/srs.js               間隔反復による出題スケジュール
js/store.js             設定・学習記録の保存（localStorage）
js/ai.js                AI添削（任意・Claude API）
js/data/index.js        レベル・シーンの定義
js/data/scenes/*.js     教材（11シーン × 4レベル × 8文）
sw.js, manifest.webmanifest, icons/   PWA（オフライン・ホーム画面追加）
tests/                  判定エンジン・音声認識処理のテスト（node --test）
```

- 依存パッケージやビルド手順はありません（ブラウザ標準の ES Modules で動きます）。
- 学習記録はブラウザ内（localStorage）に保存されます。機種変更の際は「設定 → データ」からバックアップを書き出して、新しい端末で読み込んでください。
